# Larissa's Surprise Quest

A small mobile-first, eight-level friendship game from Evans to Larissa. It uses plain HTML, CSS, and JavaScript, so there is no install or build step.

The start screen opens today's two new quests directly. A smaller replay button still starts the original surprise from Level 1.

## Open It

Double-click `index.html`. The game works directly from the folder in a browser.

The display fonts load from Google Fonts when internet is available. Safe fallback fonts are used when offline; the game itself still works.

## Add Real Photos

The seven real photos are already connected as `photos/Image 1.jpeg` through `photos/Image 7.jpeg`.

To replace one later:

1. Put the replacement in the `photos` folder. JPG, PNG, WebP, and GIF files all work.
2. Either give it the same filename or update the matching `src` in `CONTENT.photos` at the top of `script.js`.
3. Update its `alt` text with a short description.

The same seven photo slots are reused naturally across the path, collection, and gallery scenes. Slot 6 is the picture of Evans and Larissa together. Slot 7 is Evans's favourite picture of Larissa and appears as the final gallery card.

## Personalize The Words

All editable copy is inside the `CONTENT` object at the top of `script.js`. Look for the large `PERSONALIZE HERE` comment.

Start with these fields:

- `personalDetailsToReplace`: notes for an inside joke, a favorite thing, and a shared memory.
- `recipient`, `sender`, and `occasion`: names and the reason for the surprise.
- `photos`: the seven image filenames and descriptions, edited once and reused throughout.
- `paths.choices`: the three path captions and photo-slot numbers.
- `collection.items`: the five tap-to-collect captions and photo-slot numbers.
- `quiz.question` and `quiz.answers`: the memory-lock question and choices.
- `gallery.cards`: the gallery titles, captions, and photo-slot numbers.
- `final.message` and `final.signoff`: Evans's final note.

`quiz.correctAnswer` is zero-based: `0` means the first answer, `1` means the second, and `2` means the third.

Keep quote marks around text and commas after each field. Use `\n\n` inside `final.message` to add a blank line.

## Customize The Two New Quests

The editable `questA` and `questB` arrays are at the very top of `script.js`. Every entry contains:

- `question`: the question shown to Larissa.
- `options`: exactly two choices. Quest A uses a `label` and `reveal`; Quest B only needs a `label`.
- `mine`: Evans's choice, where `0` means the first option and `1` means the second.

Quest A awards a point when Larissa matches `mine`. Quest B uses `mine` to calculate the opposite: choosing `mine` shows `Wrong`, while choosing the other option shows `Right`. The order is never shuffled, so arrange the two options exactly as they should appear.

## Sound And Motion

Sound is off by default and uses lightweight tones generated by the browser, so there are no audio files to replace. The site automatically reduces or removes animation when the device has Reduced Motion enabled.

## Deploy Free On Netlify

1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag the entire `Friend` folder onto the page.
3. Netlify will provide a public link when the upload finishes.

## Deploy Free On GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the complete `photos` folder.
3. Open the repository's **Settings**, then **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.

GitHub will show the public site URL after deployment finishes.
